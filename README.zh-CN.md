# dsh-session-intent-title

[English](README.md) | 中文文档

一个轻量、零 UI 侵入的 DeepSeek Harness (DSH) 会话意图自动分类命名插件。新会话首轮提问后，自动生成带有意图类型与图标的专属标题（如 `⚡ 优化｜...`、`🐛 修复｜...`、`✨ 功能｜...`）。

## ✨ 核心特性

- **🎯 智能意图分类**：首轮提问触发，调用轻量语义提示词自动研判意图并提取核心事项。
- **🛡️ 零前端侵入**：纯服务端逻辑注册，不注入任何全局 CSS、不接管侧边栏、不改变界面结构，完美兼容原生侧边栏与 `dsh-better-sidebar`。
- **🔒 钉死锁定保护**：自动命名仅执行一次；若你在界面双击手动重命名，系统立即永久锁定，绝不重复覆盖。

## 🚀 安装与使用

### 1. 通过 DSH CLI 安装

```bash
dsh plugin --profile web add git+https://github.com/WiseXin/dsh-session-intent-title.git
```

### 2. 避免冲突（禁用默认无分类标题生成器）

在 `~/.dsh/profiles/web/cordis.patch.yml` 中禁用官方默认无分类提供方：

```yaml
- id: session-title-llm
  disabled: true
```

### 3. 重启 DSH

```bash
sudo systemctl restart dsh
```
